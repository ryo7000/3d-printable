# 抵抗用リードベンダー

小型 1/4 W のアキシャル抵抗を横一列に並べて曲げる治具を OpenSCAD で作りました。中央の曲げ芯 1 個だけで使用します。抵抗とブレッドボードの公称寸法を基準にしたモデルです。

## ファイル

- `lead_bender.scad`: 寸法を変更できる原本
- `former.stl`: 印刷用の曲げ芯（1 個）

## 標準寸法

| 項目 | 値 |
| --- | ---: |
| 対象抵抗 | 小型 1/4 W、本体長さ 3.2 mm、直径 1.7 mm、脚径 0.45 mm |
| 曲げ後の脚中心間隔 | 約 5.08 mm（2.54 mm × 2 穴） |
| 一度に並べる本数 | 最大 24 本 |
| 抵抗の並び間隔 | 2.54 mm |
| 曲げ芯の高さ | 約 6.67 mm（元の 10 mm の 2/3） |
| 脚の位置決め溝 | 幅 1.2 mm、深さ 0.8 mm |

これは本体が約 3.2 × 1.7 mm の**小型** 1/4 W 抵抗向けです。通常サイズの 1/4 W 抵抗（本体長さ約 6.3 mm）には 5.08 mm の脚間隔は使えません。その場合は `body_length`、`body_diameter`、`lead_diameter` を実物に合わせ、`hole_count = 4` などに変更してください。

## 使用方法

1. 抵抗を曲げ芯の中央のくぼみに並べ、両側の脚を浅い溝に合わせます。
2. 指で片側の脚を芯の外側面に沿って下へ曲げます。もう片側も同様に曲げます。
3. 仕上がった脚間隔を測り、必要なら `lead_diameter` または `hole_count` を調整します。曲げの戻りがあるため、最初に少数で試してください。

芯は図面上で底面を下にしてあります。Bambu Lab A1 mini の標準 0.4 mm ノズルを想定し、溝を幅 1.2 mm・深さ 0.8 mm にしました。レイヤー高さ 0.2 mm なら溝の深さは 4 層分です。印刷時は 3 周以上の外周を推奨します。Bambu Studio でスライスした後、上面の溝が 2.54 mm 間隔で 24 本ずつ両側に表示されることを確認してください。脚を曲げる肩の部分にバリが残った場合は軽く整えてください。

## STL の再生成

```sh
openscad -o former.stl lead_bender.scad
```
